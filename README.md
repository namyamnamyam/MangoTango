# MangoPen v0.4

Live: https://mangopen.vercel.app

Email signup/signin via Supabase Auth, explicit cloud backup/restore to RLS-protected works and chapters tables. Cloud uploads are private drafts. Local editing remains browser-only until manually uploaded again. Repeated uploads create duplicates; downloading merges cloud works by cloudId. No public publication, AI generation, or billing yet. Browser auth session uses localStorage. This is a beta; do not store sensitive work without independent backup.
