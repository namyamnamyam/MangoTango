# MANGOPEN — 망고펜 웹 체험판

AI 소설 창작 플랫폼 **망고펜**의 아이패드/모바일 브라우저용 정적 체험판입니다. 상표 등록 전 가칭입니다.

## 현재 되는 것

- 샘플 작품 열람 및 장르·제목 필터
- 직접 작품 생성, 회차 작성, 읽기
- 공개/비공개 표시 전환, 삭제
- 작품은 **현재 브라우저의 localStorage에만 저장**됩니다.

## 아직 안 되는 것

로그인·회원가입, 실제 AI 호출, 사용자 간 작품 공유, 서버 DB, 결제, 광고, 정산, 관리자 신고 처리는 구현되지 않았습니다. 중요한 원고는 별도로 백업하세요.

## 향후 완전한 Next.js MVP

이 체험판은 사이트 접속 및 디자인 확인을 목적으로 먼저 배포한 것입니다. 실제 AI와 클라우드 연동 기능은 서버/API 키 및 DB 설정 뒤 별도 적용합니다.
