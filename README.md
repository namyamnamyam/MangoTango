# MANGOPEN — 망고펜 웹 체험판 v0.2

https://mangopen.vercel.app

## 새 기능
- 내 서재에서 JSON **원고 백업 다운로드 / 복원** (iPad 파일 앱 사용 가능)
- 좋아요 토글, 작품 열람 횟수: **현재 브라우저 한정 테스트 지표**
- 복원 시 작품은 무조건 비공개로 가져오며 가져온 회차 본문은 길이를 검증합니다.

## 기존 기능
- 샘플 작품 읽기/검색
- 소설 직접 쓰기, 장르 설정, 공개/비공개 **로컬 표시**, 회차 저장
- 반응형 모바일/아이패드 디자인

**주의:** 로그인, 서버 저장, 독자에게 진짜 공개, 진짜 인기 조회/좋아요, AI 생성, 광고 및 결제는 아직 없습니다. 이 기기의 브라우저 데이터는 언제든 사라질 수 있으니 반드시 '내 원고 백업'을 사용하세요. 상표 등록 전 가칭입니다.

## 다음 단계 (서버 연동)
- Supabase 인증/작품·회차 테이블 및 RLS 보안정책
- Gemini AI 서버 API (키는 서버 환경변수에서만 사용)
- 실제 사용자별 공개 작품/좋아요/조회수 집계
- 신고/관리자 심사, 이용약관/개인정보 처리방침

환경변수와 Supabase 프로젝트가 연결되기 전에는 유저 데이터나 AI 호출 기능을 활성화하지 않습니다.
