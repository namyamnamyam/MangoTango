# 망고펜 v0.3 — 실제 서버 연동 준비

## 현재
- 반응형 웹: https://mangopen.vercel.app
- 추가: 회차 수정 및 삭제, 작성 중 원고 자동 임시저장(브라우저 로컬), JSON 백업/복원.
- 개발 DB 설계: `supabase/schema.sql` (저장소에 작성만 해둠. **아직 실행되지 않음**).
- AI 생성, 로그인, 계정 간 동기화, 실제 공개 게시, 광고, 결제 및 정산은 아직 미구현.

## 실제 서비스 활성화 전 체크
1. Supabase 프로젝트 연결 (프로젝트가 없는 경우 생성 여부/비용 먼저 확인).
2. SQL은 연결 대상 프로젝트를 확인한 뒤 migration으로 적용하고 RLS 검증.
3. Supabase Auth 설정 (이메일 확인, 사이트 URL/리다이렉트, 악용 방지).
4. 클라이언트에는 프로젝트 URL과 **publishable** 키만 사용. `service_role`/secret 키를 클라이언트·GitHub에 올리지 않음.
5. 소설 콘텐츠 신고, 숨김/삭제, 개인정보 처리방침, 이용약관, 저작권 신고 체계 마련.
6. 계정 연동 뒤 익명 사용자와 A/B 계정을 이용한 비공개·수정 권한 검증.
7. AI 호출은 서버에서만 인증, 일일 횟수 제한, 비용 통제 및 출력 검토 후 활성화.

주의: SQL은 신규 비어 있는 Supabase 프로젝트용 초안입니다. 기존 테이블에 덮어쓰지 마세요.
